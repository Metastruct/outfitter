# PAC3 help for integrating Outfitter

Integrates Outfitter with [PAC3](https://github.com/CapsAdmin/pac3) — apply Outfitter outfits as part of a PAC3 outfit.

EXPERIMENTAL. Backwards compatibility not guaranteed! 

## Usage

1. Apply an Outfitter outfit normally.
2. In PAC3, add an **Outfitter Outfit** part to your outfit.
3. **Double-click** the part in the PAC3 tree to import the current Outfitter outfit into the `OutfitData` field.
4. Save the PAC3 outfit.
5. Whenever the PAC3 outfit is worn, the Outfitter outfit auto-applies. When removed, it clears.
